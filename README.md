# Wave：最小波形显示 Demo

Windows 原生 C++20 / Dear ImGui / ImPlot / DirectX 11。

实现**批量接收数据、缓存、波形显示和交互**，并提供本机 TCP 外部数据源验证 Demo。设备侧串口、USB、CAN 等通信由独立程序负责。

## 运行

高频真实播放音频：独立运行 `run-audio-source.cmd`，读取默认输出设备的 WASAPI 回环音频并批量发送，不启动 Wave、不录制文件。可以与 `run-source.cmd` 同时使用，Wave 的右键菜单平铺显示所有可选数据，不自动勾选。使用方法与缓冲区建议见 [音频数据源](examples/AUDIO_SOURCE.md)。

双击根目录的 `run.cmd`，或直接运行 `build/WaveDemo.exe`。程序默认监听本机 TCP 18765，等待外部数据，不再产生模拟信号。无需 --system-source 参数。

外部系统监测：单独双击 `run-source.cmd`。两个程序独立启动、独立退出，顺序不限；Wave 未打开时，数据源等待并重连。运行 `run-source.cmd 5` 每次传送 5 组。关闭控制台结束采集，关闭 Wave 不结束采集。旧联合启动器已移除。协议范围见 [外部数据源说明](examples/SYSTEM_SOURCE.md)。

默认只有一个黑底波形窗口，连接后不自动选择信号，右键勾选后显示对应颜色的波形；坐标轴和网格保持简洁。顶部提供 `新增窗口` 和 `设置`。图例只显示信号名称，不显示单位后缀；隐藏信号的名称使用可读灰色。右键菜单内提供 `Zoom`，右侧方框显示勾选状态，默认关闭，单击切换；不显示冻结、跟踪或自由状态文字。

- `新增窗口` 添加波形窗口，窗口自动纵向平铺，最多 6 个，不显示窗口编号和窗口间分隔线。
- 在窗口内通过右键菜单勾选要显示的通道；底部的 `删除窗口` 删除当前小窗口，不清空共享数据；最后一个窗口也可删除，再通过 `新增窗口` 添加。
- 左键平移、右键拖动和滚轮缩放保持当前跟随/暂停状态；实时跟随时最新数据始终位于右侧，包括按住左键或右键拖动的过程中。
- 在主波形区域左键双击，冻结当前整个显示缓冲区，所有窗口共用同一份数据，后台接收继续。
- 冻结期间可自由拖动两轴、围绕鼠标缩放、切换通道及查看整个缓存，数据不会被后台覆盖。再次双击，恢复显示缓冲区更新：跟踪窗口回到最新数据，自由窗口保留原视区，两轴尺度都保持不变。
- `Space` 与双击是同一操作，可交替使用；长按 Space 只切换一次。菜单栏不再提供冻结或实时按钮。
- 冻结后在主绘图区中键双击执行一次 Auto：展开当前窗口可见数据的完整冻结缓存时间范围，再执行一次 Y 轴适配，保留持续 Y 自适应原有开关状态。已清空的数据不恢复；X 联动开启时同步其他窗口的 X 范围；实时状态不触发。中键拖动仍用于矩形框选。
- 冻结后，在主绘图区按住鼠标中键（滚轮）拖出白色细线矩形，松开后放大到框内范围；支持反向拖动，按 Esc 取消，小于 5 像素的框选忽略。框选关闭当前窗口的 Y 轴自适应；开启 X 轴联动时只同步其他窗口的 X 范围。实时状态、图例、坐标轴标签和 Zoom 缩略图不启动此框选。
- 实时跟随时左键拖动可上下平移 Y 轴，时间轴持续追随最新数据；冻结或查看历史时可自由平移两轴。

| 操作 | 效果 |
| --- | --- |
| 按住右键向右拖 / 向左拖 | 连续放大 / 缩小 X 轴 |
| 按住右键向上拖 / 向下拖 | 连续放大 / 缩小 Y 轴 |
| 先按住 `Shift` / `Ctrl` 再右键拖动 | 只改变 X / Y 轴 |
| 右键单击 | 打开菜单；拖动结束不会弹出菜单 |
| 左键拖动 | 实时跟随时平移 Y 轴；暂停或查看历史时平移两轴 |
| 波形区域内滚轮 | 同时缩放 X/Y 两轴；实时跟随时最新数据始终位于右侧 |
| Y 轴数字区域滚轮 / `Ctrl` + 滚轮 | 只缩放 Y 轴，关闭 Y 轴自适应，保持时间轴跟随状态 |
| X / Y 轴数字区域左键拖动 | 只平移对应轴，按下时锁定轴向；实时拖动 X 轴保持跟随，不自动冻结；手动暂停后可平移 X，Y 轴拖动保持原状态 |
| X / Y 轴数字区域右键拖动 | 只缩放对应轴，离开区域后仍保持轴向锁定；鼠标保持普通箭头 |
| X 轴数字区域滚轮 | 只缩放 X 轴 |
| 波形区域内左键双击 / `Space` | 全部窗口冻结 / 恢复缓冲区更新；冻结时自由交互，恢复时保留两轴尺度 |
| 右键菜单中单击 `Zoom` | 展开 / 收起当前窗口的整段缓存概览，关闭时保留主图范围 |

实时右键缩放时，X 轴围绕最新数据调整跨度，Y 轴以按下位置为锚点；暂停或查看历史时，两轴均以按下时的数据位置为锚点。可以斜向拖动同时调整两轴，拖回按下位置时恢复原来的尺度。右键缩放灵敏度为每移动 120 个逻辑像素，跨度变化 e 倍；右键移动 3 像素后进入缩放。

各窗口独立保存实时显示的时间跨度，滚轮调整后会持续生效。查看历史或冻结缓冲区时，滚轮围绕鼠标位置缩放，不会自动恢复实时跟随或缓冲区更新。Y 轴滚轮区域限于左侧数字区域；X 轴数字区域滚轮只缩放 X；绘图区内滚轮同时缩放 X/Y。

双击和 Space 统一切换全局冻结状态，冻结后拖动和缩放都不会解除冻结。查看整个缓存的自由窗口恢复更新后若原区间已经过期，会保留视区并显示提示，可通过拖动和缩放调整视区。图例双击只操作图例，不会冻结或恢复缓冲区。

右键菜单中的 `Zoom` 默认不勾选，单击开启或关闭当前窗口的缩略图，开启后右侧显示勾选；每个窗口独立控制。缩略图上右键单击也可呼出带 `Zoom` 复选框的菜单，取消勾选直接关闭缩略图，与主窗口菜单同步。`Zoom` 概览显示整段缓存的时间范围，并用选框标出主图正在查看的区间。冻结或自由浏览时，拖动选框内部平移时间区间，拖动左右边缘调整跨度，点击框外可定位到该时间附近；概览内滚轮也只缩放时间轴。实时跟踪时，拖动左边界或点击概览调整时间跨度，右端始终保持最新数据，不自动冻结或改变其他窗口。要稳定检查某段历史，可先双击主波形冻结，再操作概览。

概览只控制 X 轴，不修改 Y 轴范围或自适应设置。选框用细边线按真实时间比例显示，不设最小显示宽度；小于一个像素时显示细竖线。仅鼠标命中区适当扩大，冻结时窄框中央可拖动，两侧可调整边界，滚轮可继续精细缩放；悬停显示当前时间跨度。预览同步绘制当前窗口全部已选通道，颜色与主图一致，共用纵轴尺度；密集波形使用逐像素最小/最大值包络，稀疏波形使用折线，选框外的区域略微压暗；按概览像素宽度查询已有极值摘要；只在展开时查询，与主图共用当前数据池或冻结快照，不另复制缓存。概览内双击、右键和拖动不会同时触发主图的冻结、平移或菜单。

界面保留纯黑波形背景，使用 16 像素 Windows 自带微软雅黑，文字和图例按层次提亮，曲线使用不透明细线；字体与布局随窗口所在屏幕的 DPI 缩放。当前为 Windows x64 演示版本。

## Y 轴自适应

每个窗口右键菜单提供 `Y 轴自适应` 复选框，默认开启。`设置 → Y 轴自适应` 是一次性批量开启操作，相当于逐个为现有窗口勾选，之后仍可各自独立调整。只根据当前 X 视区内实际显示的信号适配，隐藏信号不参与。手动拖动或缩放 Y（包括绘图区滚轮同时缩放 X/Y）会自动取消当前窗口的勾选；只操作 X 或接收 X 联动不改变该开关。重新勾选可恢复。冻结与恢复均保留各窗口的开关状态；手动 Y 范围保持不变，自适应窗口按可见数据重新计算。

## X 轴联动

`设置 → X 轴联动` 右侧复选框默认开启。开启时，新增窗口立即继承当前窗口的 X 轴跨度与查看位置，添加信号无需再操作一次 X 轴；关闭时新增窗口使用独立默认视区。实时模式下，在任意窗口缩放 X 轴或调整 Zoom 跨度，会同步所有窗口的时间跨度并继续跟随最新数据；暂停后横向拖动、缩放或操作 Zoom 选框，会同步所有窗口的 X 轴起止时间；Y 轴始终独立。开启开关不会立即改变视区，下一次 X 轴操作才同步；关闭后保持当前视区并恢复独立查看。关闭联动后实时和暂停均可独立调整；恢复实时后保留联动后的跨度并跟随最新数据。

窗口右键菜单的 `清空数据` 只隐藏本窗口清空时刻之前的数据，主图与 Zoom 一致，保留信号选择和缩放，不删除共享历史，不影响其他窗口；X 联动不会扩大清空范围。实时下继续显示新数据，冻结下保持空白，恢复后显示清空时刻之后的数据。`设置 → 清空全部缓冲区` 才会删除共享历史和冻结快照，影响所有窗口，但保留窗口与设置，后台接收继续。

## 缓冲区设置

通过 `设置 → 缓冲区点数` 修改应用级的每通道保留点数，所有窗口共享，新增窗口不重复分配采样缓存。默认 100,000 点 / 通道，允许 8–2,000,000 点，点击“应用”生效。右侧面板仅显示当前点数文本框及同一行的“应用”按钮。缩小保留最新数据，扩大后随采样填满；冻结快照不变，恢复后使用新容量。设置仅在本次运行生效。

## 数据与性能设计

外部系统数据 Demo 为每通道 5 samples/s，默认 100k 点可保留约 20,000 秒。Wave 接受多个独立数据源，每个来源拥有独立频率、时间模式和缓存，内部映射到公共时间轴。TCP v2 包格式兼容，每个连接注册 1–64 个同步通道，总计最多 256 个；单点可使用接收时间，批量数据按频率与序号计时。界面只展示数据名称，重复名称自动加编号，悬停可查看是否仍在更新。模拟源仅用于回归测试。完整协议、限制和 Python 客户端见 [通信协议](examples/PROTOCOL.md)。

显示采用垂直同步，实际刷新率取决于显示器和负载。数据池使用有界环形缓存。缩小时按查询区间分桶，保留每桶首点、最小值、最大值、末点并按时间排序，最多提交约 `4 × 绘图区宽度` 个点/曲线。摘要分层维护，避免每一帧扫描全部历史。放大后返回原始采样。

原始数据不因显示降采样而改变。冻结显示缓冲区通过复制当前缓存建立一份所有窗口共享的只读快照实现，后台 `DataStore` 仍正常接收和覆盖；恢复更新后释放快照并重新读取后台数据池，不回放冻结期间的数据。快照只在进入冻结时创建，不逐帧或逐窗口复制，内存占用会暂时上升；该操作适用于此 Demo 的小型缓存。当前没有长期录盘、导出或无限历史。

## 接入自己的数据

`src/wave_view.hpp` 是显示组件接口，`src/data_core.hpp` 是数据接收接口。显示组件不引用模拟信号源。

```cpp
#include "data_core.hpp"
#include "wave_view.hpp"

wave::DataStore data(20'000.0, 30.0, {
    {"Current", "A"}, {"Speed", "rpm"}
});
wave::WaveView view(data);

// 在你的接收线程中按批写入，每一帧包含所有通道：
// 第0帧 Current, Speed；第1帧 Current, Speed；...
std::vector<float> batch = {1.0f, 1000.0f, 1.1f, 1001.0f};
data.append(0, batch); // 第一个参数为该批首帧的绝对样本序号
// 下一批应从第2帧开始：data.append(2, next_batch);

// 在已经初始化 ImGui / ImPlot 的 GUI 帧循环里：
view.draw();
```

显示线程调用 `draw()`，后台线程可以同时 `append()`。数据池必须比显示组件活得更久。批次按“帧优先、通道交错”排列，数值必须有限，长度必须为通道数的整数倍；接口会复制数据，调用返回后调用者可以重用输入缓冲。

上述单个 DataStore 的等间隔接入示例假设所有通道共用固定采样率、统一时间基准、按顺序写入。时间轴为 `sample_index / sample_rate`。样本序号不连续时，会清掉旧段并开始新的连续段，避免跨丢样区间连线；单个等间隔数据池不混用不同频率，也不做乱序合并。多数据源由 SignalHub 管理独立数据池并映射到公共时间轴；单点接收时间模式与 TCP 接入方式见通信协议。

## 构建

已准备的本地微软编译工具可通过以下命令使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\build-msvc.ps1
```

默认构建 Wave、两个独立数据源及四组测试，并运行全部测试。`-TestOnly` 仅构建/运行通信、数据、缩放计算和波形交互测试，不创建原生窗口、不编译 Win32/DX11 后端；`-SkipTests` 仅构建程序。重建前关闭正在运行的 Demo。该便携环境只存放于项目 `.tools`，不修改系统环境变量。

已有 Visual Studio 2022（C++ 桌面开发工作负载）和 CMake 时，也可以使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1 -SkipToolchain
cmake -S . -B build-cmake -A x64
cmake --build build-cmake --config Release
ctest --test-dir build-cmake -C Release --output-on-failure
```

也提供 `build.ps1` 和 `scripts/bootstrap.ps1` 的 LLVM-MinGW 路线。本轮功能与回归测试使用 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 构建验证；工具链放在项目 `.tools` 中。

依赖固定为 ImGui `v1.92.9b-docking`、ImPlot `v1.0`。许可证和来源见 `THIRD_PARTY.md`。

## 验证

默认测试包含四部分：

- 通信层：实际本机 TCP 连接，验证元数据注册与确认、单点接收时间、批量传输、多源并发、慢连接隔离、重连、清空作用域及非法消息拒收。

- 数据层：环形缓存覆盖、正负单采样点尖峰、查询顺序/范围、随机批次与原始数组对照、冻结快照独立性，以及模拟源启动/停止。
- 缩放计算：拖动方向、固定锚点、单轴修饰键、分帧结果一致性、拖回原点、采样分辨率限制和极端输入。
- 交互集成：向真实 ImGui 队列注入鼠标和键盘事件，由真实 `WaveView` 和 ImPlot 帧循环验证左右键拖动期间持续跟随、实时左拖只平移 Y、冻结及历史模式下自由平移两轴、冻结时的缩放锚点、释放后不弹菜单、右键单击弹菜单、图例切换；还验证双击冻结所有窗口后自由检查数据、恢复时保留两轴尺度、实时滚轮缩放后跨度保持，以及 Y 轴滚轮分区。此测试不需要图形后端。

冻结交互还验证了后台环形缓存覆盖后冻结数据仍完整、冻结滚轮保留鼠标锚点、恢复更新后各窗口保留独立跟踪模式，以及长按 Space 不会重复切换。

实际窗口的短时运行检查：

```powershell
Start-Process -FilePath .\build\WaveDemo.exe -ArgumentList '--smoke-test' -WorkingDirectory .\build -Wait
Get-Content .\build\smoke-test.json
```

该模式运行约 12 秒；未连接数据源时数据应始终为空。报告实际帧数、CPU 帧内耗时（不含等待垂直同步）、TCP 接收组数、拒收数、序号缺口和每帧最大提交点数。它是当前机器上的短时检查，不能代表长期负载、真实设备传输或所有显卡的性能。
